# Showcase Scope

This repository is a curated portfolio case study for **HeartNote**, a live product co-founded and built collaboratively with Ilay Admoni.

Its purpose is to explain my contribution clearly without duplicating or republishing the full production system.

## Included

- product and UX case study documentation
- branding and interaction-design rationale
- collaboration and ownership documentation
- selected user-facing front-end examples
- approved product screenshots when added
- links to the live product and collaborative source repository where appropriate

## Intentionally excluded

- production environment files
- AWS or deployment configuration
- database credentials or connection details
- authentication secrets
- customer or user data
- infrastructure scripts
- production logs
- complete source history
- the full collaborative codebase

## Attribution

HeartNote is a shared product.

This showcase describes my primary contribution in product concept, branding, UI/UX, interaction concepts, front-end experience, Hebrew-first content and product iteration.

It does not claim sole authorship of the complete production system.

## Code samples

Any code samples in this repository are selected specifically because they demonstrate patterns relevant to my front-end contribution.

They are provided for portfolio discussion and are not intended to form a deployable application.

## Production separation

The live HeartNote product and its operational repository remain separate from this showcase.

Changes made here do not deploy to or modify the production application.
